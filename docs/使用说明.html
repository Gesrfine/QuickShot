QUICKSHOT 1.3.6 / 快投

完整解压，
双击 QuickShot.exe。

本轮只提供便携版，最终版本再制作安装程序。支持 Windows 10/11 x64，无需额外安装 .NET，开机自启默认关闭。在 1.3.4 的截图投递流程上增加本地设置。

截图快捷键（默认 Alt + Shift + D）→ 10 秒内按 C 或组合键 → 确认附件后发送

解压、运行、加载扩展

  1. 将 QuickShot-Portable-win-x64.zip 完整解压到长期保留的专用目录，不要在压缩包中运行。
  2. 双击根目录的 QuickShot.exe。首次运行会为当前用户登记浏览器连接，设置、缓存和日志存入目录内自动生成的 data。
  3. 打开 Edge 的 edge://extensions，启用“开发人员模式”，点击“加载解压缩的扩展”，选择此解压目录内的 extension 文件夹。

不要同时运行多个副本。移动便携目录后，重新运行 QuickShot.exe，并在 Edge 重新加载新目录中的扩展。完整绑定配置保存在当前 Edge 用户配置内，移除扩展后可能需要重新绑定。

从旧版升级

先从托盘退出快投，完整解压新版并双击根目录的 QuickShot.exe，再对 Edge 中的快投扩展点重新加载，确认版本为 1.3.6。程序和扩展必须同时更新。更换目录时须加载新目录的 extension；要保留本地设置，同时保留原来的 data 文件夹。旧安装版可先运行其 Uninstall.cmd，再使用便携版。

精简便携包

压缩包根目录只有 QuickShot.exe、extension 文件夹与 使用说明.html，共 18 个文件。直接双击程序即可启动，移除功能在程序内。说明是独立文件，不嵌入 EXE；删除本说明不会影响截图投递和移除功能。启动、卸载脚本、便携标记、README、验证报告、测试与构建文件均不进入便携 ZIP。

第一次绑定

  1. 运行快投，把扩展固定到工具栏，进入 DeepSeek、豆包等支持粘贴图片的页面。
  2. 点击快投图标，填名称。点击投递快捷键框，直接按组合，例如 Ctrl＋Alt＋C，最多同时三个键。
  3. 设置“默认网址”，必须属于当前网站；豆包可填写 https://www.doubao.com/chat/。
  4. 点击绑定，允许访问网站，再点聊天输入框完成定位。
  5. FastStone 与快投的截图快捷键须相同，默认均为 Alt＋Shift＋D；FastStone 还须设置为截图后自动复制。新截图后右下角默认显示紧凑目标列表与 10 秒倒计时，可以在主窗口关闭提示；按对应投递快捷键提交，快投切到聊天、聚焦输入框，按键释放且焦点和剪贴板复核通过后粘贴。

已有草稿保留，光标留在输入框。确认附件后由你发送；快投不会按 Enter 或点发送。同一投递快捷键只能绑定一个目标，请勿与截图快捷键相同，可在管理页修改或重新定位输入框。

隐藏右下角提示

双击托盘中的快投图标打开主窗口，取消勾选显示右下角提示。截图倒计时、投递成功和失败等提示都会隐藏，10 秒期限和快捷键功能照常运行；操作状态仍可在主窗口查看。需要提示时重新勾选，默认开启。

修改截图快捷键

  1. 双击托盘中的快投图标，点击主窗口的截图快捷键输入框，按下新的按键或组合。
  2. 最多同时三个键，默认 Alt＋Shift＋D；支持 PrintScreen、F1–F12 单键，普通字母或数字须搭配 Ctrl、Alt、Shift 或 Windows 中至少一个修饰键。不要与已绑定的投递快捷键重复，然后点击保存快捷键。
  3. 自行在 FastStone 中设置相同的截图按键，并保留截图后自动复制设置。

快投只监听并透传该按键，不修改 FastStone。两边设置不一致时，截图可能无法进入投递模式。截图快捷键与扩展中的目标投递快捷键是两项独立设置。右下角提示与截图快捷键设置保存后立即生效，保存在便携目录的 data/settings.json，下次运行自动恢复。

10 秒内一次有效

只有截图产生新的图片剪贴板才开启投递。取消截图、普通复制图片、旧剪贴板不会开启。按下有效投递快捷键之前，其他按键、任意鼠标按钮、Esc 或超时，立即取消这次资格，之后按正确键也不补投。长按不重复粘贴，平时打字不受影响。

组合键修饰键可依次按下，最后须同时按住；只按修饰键又松开也会取消。截图组合原本按住的键松开不算误操作。有效快捷键提交后，其他按键、鼠标操作或 Esc 不再直接取消投递；修饰键未放开时会等待释放，再重新核对焦点和剪贴板。粘贴前剪贴板变化、断线或焦点核对失败仍会停止；鼠标若切走目标窗口，也无法通过焦点保护。

标签页与 Edge 应用窗口

目标网站候选页行为
只有 1 个使用当前聊天，激活窗口、聚焦输入框并附图
有多个停止；请只保留一个后重新截图
没有打开绑定的默认网址，待页面与输入框就绪后投递

普通 Edge 窗口及 Edge 应用模式窗口均计入，其他网站不影响。应用窗口须属于启用了快投扩展的同一 Edge 用户配置。默认网址不会跟随聊天切换改成最近地址。

后台、最小化或新打开的窗口会尝试恢复聚焦。浏览器冷启动或新建默认页面时，首次粘贴授权前的同站导航会等待页面稳定并重新定位输入框；出现多个候选页、跨站登录或输入框失效仍停止。粘贴获授权后再发生导航，也停止本次投递，绝不自动重复粘贴。

核对前台窗口、标签页、输入框和剪贴板后才粘贴。网页改版后请重新定位；每次截图最多执行一次粘贴。

退出、自启与进程

关主窗口会留在托盘，右键托盘可暂停或退出。“登录 Windows 时启动”默认关闭，取消会删除匹配的启动项。Edge 启动和后台断线不会隐式拉起快投，扩展的“启动 / 连接快投”按钮可显式启动。

任务管理器“详细信息”中为 QuickShot.exe。连接后可能有两个同名进程；带 chrome-extension://… 参数的是通信进程。用“打开文件所在位置”可辨认副本。

文件、体积与移除

程序在根目录 QuickShot.exe，扩展在 extension，自带所需运行组件。直接双击 使用说明.html 查看说明；主窗口不设置说明按钮，不需要时可删除本文件。程序默认以便携方式运行。本地设置、缓存与日志首次运行后写入 data；运行数据和浏览器连接文件不随包分发。请保留 QuickShot.exe 与完整 extension 文件夹。

完整的投递按键绑定与输入框定位保存在当前 Edge 用户配置的扩展存储；便携目录内的 data 保存本地设置、缓存和日志，单独复制目录不会迁移全部绑定。

移除时点击主窗口的移除快投，或托盘菜单的移除快投连接并退出，程序会解除属于当前副本的浏览器连接及匹配的自启，然后退出。再从 Edge 移除扩展，最后自行删除便携目录。程序保留本地数据，需要时先备份 data。日志不记录图片、剪贴板内容或聊天正文。

确认附件后再发送

“已执行粘贴”只表示动作发生，请在网页确认附件。关闭右下角提示后可在主窗口查看状态。网站必须本身支持 Ctrl＋V 图片，登录、大小与模型限制由网站处理；失败后图片仍留在剪贴板，可自行处理。

支持一个 Edge 用户配置、HTTP/HTTPS 主页面 textarea 和 contenteditable。暂不支持无痕、跨域 iframe、Shadow DOM 输入框或管理员运行的 Edge。完整 FastStone → DeepSeek / 豆包流程须在已登录页面验收，确认附件、草稿和手动发送符合预期。
