## 行为与保护

- 新图片通过 Windows 剪贴板事件触发；不要求截图快捷键、不查询复制进程，不限制来源。仅检查图片格式，不读取或复制图片内容进程序内存。启动与恢复监听时建立序号基线，旧图片与重复通知不能触发。复制文字或文件不触发。
- 保留用户选择的 10 秒窗口、按目标键之前其他键鼠或 Esc 取消。复制组合键已按住的键会记录，松键不误取消，重复按住不能触发。一次复制只允许提交一次。
- 粘贴提交后普通输入不取消；仍按住的键会等待释放并重新验证焦点。剪贴板变化、跨站、多个候选、输入框失效、断连和超时均停止。网页与输入框就绪后才发真实 Ctrl+V，不发送消息，不把“执行粘贴”当作附件上传成功。
- 保留唯一目标恢复、默认网址、app/普通/最小化窗口与同站导航重准备。新协议为 3，旧程序/扩展会被拒绝。连接消息按原始连接核验，不允许旧端口的延迟确认把新连接错误标记就绪。
- 空闲没有键盘钩子、鼠标钩子和轮询计时器。键盘钩子保留到被消费按键的 keyup 完成后卸载。提示窗口首次需要时才创建；关闭提示时无需构造；主窗口关闭后释放窗口资源，托盘仍运行。
- 偏好、缓存、诊断和 Native Host 清单在便携目录 `data/` 按需生成。Edge 完整绑定继续保存在浏览器用户配置。当前用户 Native Host 使用 `com.clipboardsender.edge`；不会修改旧产品的登记。解除连接只清理当前副本匹配的登记及自启，保留数据。
