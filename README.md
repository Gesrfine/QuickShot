# 快投 QuickShot 1.3.6

**截图快捷键调用 FastStone（默认 Alt＋Shift＋D）→ 框选后自动复制 → 10 秒内按投递快捷键 → 在 Edge 确认附件，手动发送。**

例如 C、Ctrl＋C、Ctrl＋Alt＋C，每个快捷键对应一个接收目标，最多同时按三个键。图片经系统剪贴板和真实 Ctrl＋V 粘贴。

## 本轮只使用便携版

本轮提供 `QuickShot-Portable-win-x64.zip`，安装程序待最终版本再制作。支持 Windows 10/11 x64，自带运行组件，无需额外安装 .NET。“登录 Windows 时启动”默认关闭。

1. 将 ZIP **完整解压**到希望长期保留的位置，不要在压缩包中运行。
2. 双击根目录的 `QuickShot.exe`。首次运行会为当前用户登记浏览器连接，设置、缓存、日志写入目录内自动生成的 `data` 文件夹。
3. 在 Edge 打开 `edge://extensions`，启用“开发人员模式”，点击“加载解压缩的扩展”，选择**解压目录内的 `extension` 文件夹**。
4. 扩展固定 ID 为 `kgjahiekhopambbcmenggajjghlmbhel`。不要同时运行多个快投副本。

移动便携目录后，重新运行 QuickShot.exe 登记新路径，并在 Edge 重新加载对应目录的扩展。完整绑定配置属于当前 Edge 用户配置，移除扩展后可能需要重新绑定。

便携目录里的 data 保存本地设置、缓存和日志；完整的投递按键绑定与输入框定位保存在当前 Edge 用户配置的扩展存储。单独复制便携目录不会迁移全部绑定。

## 升级与移除

升级前从托盘退出快投，将新版完整解压到专用目录，双击根目录的 QuickShot.exe，再到 `edge://extensions` 对快投点**重新加载**，确认扩展版本为 **1.3.6**。程序与扩展必须同时更新。若换了解压位置，请移除旧目录的扩展并加载新目录的 extension；要保留本地设置，同时保留原来的 data 文件夹。

原有快捷键和绑定保存在 Edge 用户配置中。旧安装版可先运行其 Uninstall.cmd，再改用便携版；原安装版缓存与日志保留。

移除便携版时，点击主窗口的**移除快投**，或托盘菜单的**移除快投连接并退出**，程序会解除属于当前副本的浏览器连接及匹配的自启项，然后退出。再从 Edge 移除快投扩展，最后自行删除整个便携目录。程序会保留本地数据；需要时先备份 data。

1.3.6 在 1.3.4 的截图投递流程上增加本地设置，保留精简便携结构。便携 ZIP 根目录只有 **QuickShot.exe**、**extension 文件夹**与**使用说明.html**，共 18 个文件。直接双击 EXE 启动，移除功能在程序内；说明是独立文件，**删除不会影响截图投递及移除功能**。无需启动、卸载脚本或便携标记，README、验证记录和构建测试文件不进入便携 ZIP。

## 第一次绑定与使用

1. 运行快投，把 Edge 扩展固定到工具栏，进入 DeepSeek、豆包等能用 Ctrl＋V 接收图片的页面。
2. 点击快投图标，填写名称。点击“投递快捷键”框，按下组合，例如 Ctrl＋Alt＋C。
3. 设置“默认网址”，初始为网站首页，必须属于当前网站。可以填写实际入口，例如 `https://www.doubao.com/chat/`。
4. 点击“绑定当前页”，允许访问该网站，再点击聊天输入框完成定位。
5. FastStone 与快投的截图快捷键须相同，默认均为 Alt＋Shift＋D；FastStone 还须设置为截图后自动复制。新截图后右下角默认显示紧凑的快捷键、目标列表和 **10 秒倒计时**，可以在主窗口关闭提示。
6. 按目标快捷键提交本次投递。快投切到目标 Edge 窗口、聚焦输入框，并在按键释放且焦点和剪贴板复核通过后粘贴；已有文字保留，光标留在输入框。
7. 确认网页出现附件后手动发送。快投不会按 Enter 或点击发送。

在“管理所有接收目标”中可改投递快捷键、名称、默认网址，也可打开目标、重新定位输入框或删除绑定。一个快捷键只能分配给一个目标；请勿让投递键与截图快捷键相同，Esc 用于取消。Windows 保留组合可能被系统优先处理，建议投递键使用 C 或 Ctrl＋Alt＋字母。

## 隐藏提示与修改截图快捷键

双击托盘中的快投图标打开主窗口：

- **显示右下角提示**默认开启。取消勾选后隐藏截图倒计时及投递成功、失败等右下角提示，10 秒投递期限和快捷键功能照常运行；操作状态仍可在主窗口查看。重新勾选即可恢复提示。
- 点击**截图快捷键**输入框，按下新的按键或组合，再点击**保存快捷键**。最多同时三个键，默认 Alt＋Shift＋D；支持 PrintScreen、F1–F12 单键，普通字母或数字须搭配 Ctrl、Alt、Shift 或 Windows 中至少一个修饰键。不要与已绑定的投递快捷键重复。

快投只监听并透传截图快捷键，不修改 FastStone 的设置。更换时请自行在 FastStone 中设置相同组合；两边不一致时，截图可能无法进入投递模式。截图快捷键与目标的投递快捷键是两项独立设置。

两项设置保存后立即生效，并写入便携目录的 `data/settings.json`，下次运行自动恢复。

## 10 秒内只接受一次

- 只有截图产生**新的图片剪贴板**后才计时；取消截图、普通复制图片、旧剪贴板不会开启投递。
- 在按下有效投递快捷键之前，按其他键、点击任意鼠标按钮、Esc 或超时立即失效，此后按正确键也不会补投，需要重新截图。错误按键与鼠标点击仍传给原软件。
- 组合键的修饰键可以依次按下，最终须同时按住；只按修饰键后松开也会取消。截图快捷键原本按住的键松开不算误操作。
- 中文输入法按物理键识别，平时输入保持原行为；长按不重复粘贴。
- 有效快捷键提交后，其他按键、鼠标操作或 Esc 不再直接取消本次投递；修饰键仍按住时会等释放，再重新核对焦点和剪贴板。
- 粘贴前仍核对目标窗口、标签页、输入框和剪贴板。剪贴板变化、扩展断开或焦点核对失败会停止；若鼠标操作切走目标窗口，也无法通过焦点保护。

## 标签页、应用窗口与焦点

统计绑定网站在当前 Edge 用户配置内的候选页，包含普通窗口和 Edge 应用模式窗口，其他网站不影响：

| 目标网站候选页 | 行为 |
| --- | --- |
| 只有 1 个 | 使用该页当前聊天，激活窗口、聚焦输入框并粘贴 |
| 多个，即使分属不同窗口或不同聊天 | 停止，不替你选择；请只保留一个后重新截图 |
| 没有 | 打开该绑定的默认网址，等待页面与输入框就绪再投递；必要时先启动 Edge |

默认网址**不会随聊天切换变成上次访问的地址**。应用窗口须使用启用了快投扩展的同一 Edge 用户配置，且页面本身能接收图片。

后台、最小化和新打开的窗口会尝试恢复并聚焦。浏览器冷启动或新建默认页面时，在首次粘贴授权前发生的同站导航会等待页面稳定，并重新定位输入框；不会仅因初始页面仍在导航就立刻失败。出现多个候选页、跨站登录跳转或输入框失效时仍停止；粘贴已获授权后若再次导航，也停止本次投递，不会自动重试粘贴。

程序核对前台窗口、标签页、输入框和剪贴板均正确后才执行 Ctrl＋V。网页改版后请重新选择输入框；每次截图最多执行一次粘贴。

## 退出、自启与任务管理器

关闭主窗口会留在托盘；右键托盘可暂停或**退出**，双击可打开主窗口。“登录 Windows 时启动”默认关闭，取消时删除当前用户的 QuickShot 启动项。Edge 启动与后台断线不会隐式拉起快投，只有扩展的“启动 / 连接快投”按钮允许显式启动。

任务管理器“详细信息”中的进程名为 **QuickShot.exe**。通常一个是托盘程序，连接 Edge 后另有一个同名通信进程。启用“命令行”列：带 `chrome-extension://…` 的是通信进程，带 --background 或不带参数的是主程序。“打开文件所在位置”可确认正在运行哪个副本。

## 文件、体积与占用

| 内容 | 位置 |
| --- | --- |
| 程序 | 解压目录内 QuickShot.exe |
| Edge 扩展 | 解压目录内 extension |
| 使用说明（可删除） | 解压目录内 使用说明.html |
| 本地设置 | 解压目录内 data/settings.json |
| 目标缓存、日志 | 解压目录内 data |
| 完整绑定配置 | 当前 Edge 用户配置的扩展本地存储 |

程序默认以便携方式运行；首次运行后生成的 `data` 和浏览器连接文件不随包分发。请保留 QuickShot.exe 与完整 extension 文件夹。使用说明.html 可直接双击，不嵌入 EXE，主窗口不设置说明按钮；不需要时可删除，程序不会依赖它运行。

程序自带所需运行组件，无需额外安装 .NET。保留简体中文与内置英语回退，以及 WinForms、网页聚焦和图片粘贴所需组件。项目内 `docs/验证记录.md` 记录构建与隔离测试结果，不进入压缩包。

日志不记录图片、聊天正文或剪贴板内容。无需手动编辑注册表：连接位于当前用户的 `Software\Microsoft\Edge\NativeMessagingHosts\com.quickshot.edge`，自启是 `Software\Microsoft\Windows\CurrentVersion\Run` 中的 QuickShot 值。

## 支持范围与问题处理

支持一个 Edge 用户配置的 HTTP/HTTPS 主页面 textarea、contenteditable 输入框，沿用现有 FastStone 设置。暂不支持无痕、跨域 iframe、Shadow DOM 输入框及管理员运行的 Edge。

网站必须本身能粘贴图片。通用页面状态显示“已执行粘贴，请确认附件”；实际登录、附件大小和模型限制仍由网站处理。关闭右下角提示后可在主窗口查看状态。没有反应时先检查两边截图快捷键是否相同、FastStone 能否在其他软件粘贴，再确认扩展连接和目标网站是否只有一个候选页，必要时重新定位。图片仍在剪贴板，可手动处理。

## 构建与测试

项目使用 .NET 10 SDK 10.0.402、Node.js 22+、PowerShell 7。SDK 只放在 .tools/dotnet，引导脚本从微软下载并核验 SHA512。

默认发布使用固定版本 7-Zip 26.04 生成普通 Deflate ZIP；Windows 自带解压即可使用。`scripts/bootstrap-zip.ps1` 从 7-Zip 官方 GitHub 下载构建工具，核验两个下载文件及提取后 EXE 的 SHA256，只放入 `.tools/7zip/26.04`，不会安装到系统或放进便携包。压缩仅作用于下载 ZIP，程序内部程序集保持未压缩，所需运行组件保持完整。使用 `-FastArchive` 可跳过该工具，改用 .NET 压缩以加快开发回归。

```powershell
pwsh -File scripts/build.ps1
pwsh -File scripts/build.ps1 -NativeFocusTests
pwsh -File scripts/build.ps1 -SkipTests -FastArchive
pwsh -File scripts/build.ps1 -SkipTests -NoRestore
node tests/native-smoke.mjs
.tools/dotnet/dotnet.exe run --project tests/QuickShot.Unregister.Tests -c Release
pwsh -File tests/distributions-smoke.ps1
```

默认仅构建 `artifacts/QuickShot-Portable-win-x64.zip`，中间目录为 `artifacts/staging/portable`，不会重建或交付安装 EXE。以后需要安装版时显式加 `-IncludeInstaller`，该模式再执行安装器检查；便携构建不依赖旧版安装文件。

`-NoRestore` 只适用于项目 SDK 与依赖缓存已准备完整、依赖声明未变化的离线构建；首次构建先正常准备依赖。

自动测试使用独立数据、实例名和隔离 Edge 页面；安装测试仅操作项目临时目录与专用测试注册表。加 -NativeFocusTests 会短暂激活测试创建的 Edge 窗口。真实 FastStone、中文输入法和已登录 DeepSeek / 豆包附件上传仍需现场验收；测试不会发送消息。
