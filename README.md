# QuickShot 2.0.2

任意来源的新图片进入剪贴板 → 10 秒内按目标快捷键 → 切到绑定的 Edge 页面并粘贴 → 确认附件后手动发送。

仅处理图片。复制文字和文件不触发；程序启动时的旧图片不触发。按目标键前，其他按键、鼠标点击或 Esc 会取消；提交投递后普通输入不再取消，但剪贴板变化、失焦、目标异常和超时仍会停止。一次复制最多投递一次；取消或超时后需要重新复制图片。

## 运行

支持 Windows 10/11 x64。先安装 [.NET 10 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)，无需安装 SDK。便携包不捆绑运行库；运行库由电脑上的其他 .NET 程序共享。没有运行库时 Windows 的 .NET 启动提示会引导安装。

完整解压 `QuickShot-2.0.2-win-x64.zip` 到可写目录，例如 `D:\QuickShot`。包内只有 `QuickShot.exe`、`extension/` 与可删除的 `使用教程.html`；不要在压缩包中运行。升级前从托盘退出旧版，同时更新 EXE 和 `extension/`，保留 `data/`，再在 Edge 重新加载扩展并刷新目标网页。不要先移除扩展，以保留已有绑定。开机自启默认关闭，关闭主窗口后仍在托盘，右键托盘可暂停、退出。

## 绑定 Edge 页面

1. 打开 `edge://extensions`，启用“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择本目录中的 `extension`。
3. 打开能接收图片粘贴的聊天网页，点击扩展图标。
4. 设置名称、投递快捷键和默认网址，允许访问后点击聊天输入框完成绑定。
5. 用任意截图工具、网页或其他程序复制图片，10 秒内按对应快捷键。

快捷键支持单键或最多三键组合，例如 `C`、`Ctrl+Alt+C`。同一快捷键不能重复绑定。复制操作尚未释放的按键不会触发投递或取消；需要松开后重新按目标快捷键。

同站只有一个候选页时投递到当前聊天；没有候选页时打开绑定的默认网址；有多个候选页时停止，避免贴错。普通窗口、最小化窗口及 Edge 应用窗口都计入；须属于加载了本扩展的同一 Edge 用户配置。登录跳转、跨站、输入框失效或失焦时停止。不会按 Enter 或自动发送。

首次粘贴授权前发生同站导航时，会等待最终文档并重新聚焦；已授权后发生导航则停止，不会重复粘贴。“已执行粘贴”表示已发出真实 Ctrl+V，附件是否出现仍需查看网页。

## 提示、数据和移除

双击托盘图标打开主窗口，取消“显示右下角提示”即可隐藏倒计时和结果提示；结果仍显示在主窗口。程序空闲时没有轮询计时器、键盘钩子和鼠标钩子，收到剪贴板事件才检查图片格式，不把图片复制进程序内存。

2.0.2 改善窗口切换与恢复：图片有效期内临时注册系统快捷键；激活不再同步绑定外部输入线程，跳过无响应窗口。提示放在当前前台窗口所在屏幕，并在显示期间维护层级。主窗口明确区分新图就绪、输入取消和过期。Edge 临时提升的层级会在切离后恢复，无法确认窗口可见与聚焦时停止粘贴。

最小化窗口提前恢复；没有目标页时打开绑定的默认网址。所有普通窗口关闭但 Edge 后台仍运行时，交由 Edge 自身开窗，沿用其保存的位置、大小与最大化状态。页面只需输入框所依赖的 DOM 就绪，不再等待无关资源全部加载；首次授权前短暂等待同一定位的输入框重建，授权后变化仍停止。唯一 app 目标可与其他网站的普通窗口共存，同站多个候选仍停止。

实际独占全屏、反作弊及权限隔离场景尚未完成验收，不保证可切换或显示桌面提示。Windows 的前台切换限制见[微软文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)。

首次运行按需创建 `data/`，其中保存提示偏好、目标缓存、诊断和浏览器连接清单。完整绑定与输入框定位由 Edge 扩展存储保存在当前浏览器用户配置中。移动目录后重新运行 EXE，并在 Edge 加载新位置的扩展。日志不包含图片、剪贴板正文或聊天内容。

移除时点击“解除浏览器连接”，再从 Edge 移除扩展，退出后自行删除便携目录。解除连接会保留数据，仅移除属于当前副本的浏览器登记及开机自启项。任务管理器显示名为 `QuickShot`，进程名为 `QuickShot.exe`；连接后可有一个托盘进程和一个 Native Messaging 通信进程。

## 构建和版本

项目内准备 .NET 10 SDK；生成图标和浏览器回归还需要 Node.js。正常构建运行 `pwsh -File scripts/build.ps1`，已有完整依赖缓存时可加 `-NoRestore`。输出为独立版本路径 `artifacts/QuickShot-2.0.2-win-x64.zip`。

`scripts/test.ps1` 运行核心、运行时、界面与扩展检查，`-Browser` 增加隔离 Edge 回归，`-NativeFocus` 增加真实窗口聚焦和测试输入框的 Ctrl+V 验证。测试不替用户登录，不发送聊天消息。

源码、扩展、测试及构建脚本保存在 Git；SDK、运行数据和构建产物不入 Git。`v1.3.6` 保留改写前的基线，`v2.0.0` 保留通用剪贴板版本，`v2.0.1` 统一名称并加入独立 HTML 教程，`v2.0.2` 改善窗口切换、浏览器恢复与开窗位置。每个正式版本提交并建立对应标签，保留同版本的验证与包哈希记录。
